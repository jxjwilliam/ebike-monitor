# 国内第三方服务选型与研究记录

研究日期：2026-10-30。以下区分官方已证实能力、工程建议和待询价/待验证事项。官方页面会更新，采购时再次核对；未以网页功能介绍替代本项目现场验证。

## 2. 已查证的关键结论

### 2.1 地图不等于车辆数据源

高德官方公开能力包括地图、定位、地址和坐标转换等；这些接口不能据此推断具备三家品牌的实时车辆库存。高德 JS 文档说明其坐标采用 GCJ-02，适合与现有点位表对齐。[S1][S2]

高德服务条款对自动抓取、相关内容使用等设有限制。因此采购地图展示能力与取得三品牌数据权利是两件事；涉及地图截图作为商业证据保存、分析和转交时，应核实适用许可。这里不推断其他品牌的条款与高德相同。[S3]

### 2.2 国内数据库可以支持空间数据，但坐标不能错标

阿里云 RDS PostgreSQL 官方列出 PostGIS 支持，具体版本随内核与规格变化，需在选定实例上验证。[S4] PostGIS 的 `ST_SetSRID` 只设置坐标参考标识，不转换坐标，不能将 GCJ-02 数据直接改标签为 WGS84。[S5]

### 2.3 云端视觉必须核实推理边界

百炼官方支持图像及视频理解，可作为辅助分析候选，但文档没有保证本项目车辆计数准确率。[S6]

本次查到的北京地域说明将接入/存储地域与推理部署范围分开，并提示部分新模型默认使用“中国弹性区”。因此仅看北京域名不足以确认推理严格限于中国内地。使用云视觉前，必须对具体模型和版本核实仅境内推理条件；不满足则用境内自部署或人工。[S7][S8]

百炼官方国际站产品说明区分按量 API 与个人订阅的数据条款，因此不能混用套餐承诺；中国站企业账户的最终条款仍需核对实际签约协议。生产建议使用企业按量 API；中国站隐私说明确认调用数据可能留存，不能把“不用于训练”解释成“不保存”。[S9][S10]

### 2.4 OCR 解决文字识别，不直接解决车辆匹配

PaddleOCR 官方项目提供中文等文字识别及部署能力，可读取时钟、比例尺和异常提示。车辆图标检测、遮挡拆分和跨时点匹配仍需另外验证，不能用 OCR 通用基准推导电单车任务表现。[S11]

### 2.5 Android 采集存在系统边界

Android 官方 MediaProjection 要求用户对采集会话授权；Android 14 及以上涉及前台服务与令牌使用限制。单 App 窗口共享也不等于自动跟随三家 App 切换。技术选型需实测，不能承诺后台静默、无感、永久授权截图。[S12]

### 2.6 证据适合私有对象存储与短时授权

OSS 官方支持 STS 临时凭证和客户端直传。工程上将授权限制到任务对象及时间，服务端校验完整性，原件和标注分离。[S13] Celery 官方建议幂等任务；因此本方案用数据库唯一键、Outbox 和状态机处理至少一次消费，不能只配置重试就声称不会丢失或重复。[S14]

## 3. 国内上线需要落实的事项

- 使用中国内地服务器对外提供网站服务，按域名、主体与接入商要求办理 ICP 备案。[S15]
- 若上线 App/小程序等互联网信息服务，结合具体形态核实 APP 备案等适用要求；不把“内部使用”或“H5”当作自动豁免结论。[S16]
- 采集图片、账号和设备日志做最小化处理。生产数据、备份、日志、监控与推理链路均按项目约定在境内；外部模型仅接收必要的脱敏图像区域。
- 平台账号由有权人员管理；不集中收集验证码，不把手机号、会话 Cookie、API Key 放到表格、代码库或日志。采集授权应覆盖来源及商业交付，不只覆盖设备操作。
- 地图许可、平台数据授权、信息服务备案与个人信息处理分别核对。是否需要额外资质，按实际业务交由企业相应负责人评估；本文不预设所有项目都需要同一套资质。

## 4. 供应商询问模板

1. 具体覆盖哪家品牌、哪座城市？数据是原始授权接口、App 显示采集还是推算？
2. 是否提供实际刷新时间、稳定匿名车辆 ID、上下线原因、边界事件或调度记录？
3. 每十分钟一次是否遗漏期间进出？对真实流量有什么可核验依据？
4. 同一时点可并发多少点，品牌之间时间偏差如何证明？
5. 截图/原始响应能否保存与交付，允许保存多久，模型训练是否另需授权？
6. 计费按城市、点位、请求、设备还是有效交付量？失败、漏采、复核如何计费？
7. 提供 1 点、1 小时、三品牌样包：21 份时点证据、18 条区间记录，以及权限和时间说明。

本次没有注册或购买服务、调用三品牌数据接口，也没有验证设备兼容性。钉钉文档页面可访问但正文无法由检索工具读取，故只列为候选，不对当前鉴权方式或配额作已验证承诺。[S17]
