# 电单车采集与核验平台：中国部署方案索引

日期：2026-10-30。状态：研究与设计草案，可用于立项、供应商沟通和开发拆解；不代表已取得三品牌数据接口或已通过现场验证。

## 1. 推荐结论

采用 **Vue 3 管理后台＋FastAPI 模块化后端＋独立 Python 识别 Worker＋PostgreSQL/PostGIS＋阿里云 OSS**，部署在中国内地。第一版用现场人工截图上传打通任务、质检、复核和交付；同时对接品牌方或有权提供数据的供应商。满足条件后，再增加 Android 辅助采集与结构化数据适配器。

不要把“每十分钟两张图的差异”承诺成“十分钟内真实发生的全部流入流出”。产品同时保存快照净变化、端点可见变化和连续事件流，交付时明确口径。没有足够证据的指标标记不可判定。

“中国方案”在本文指服务部署、存储、推理、地图、账号和运维链路能够在中国内地运行；不等于全部软件及硬件均为国产。若要求信创、国产 CPU/GPU 或国密，须单独做兼容性验证，不能直接沿用本选型承诺。

## 4. 待确认、但不阻碍做原型的事项

1. 四个时段的具体时间、每月采集日期和重复天数。
2. 每城四时段是否重复使用同一批停车点。
3. 真实流量还是端点变化，调度入是否包含在总流入中。
4. 三品牌数据来源、字段、授权范围、调用额度、保存及转交权利。
5. 监控中心、边界、时间容差、验收误差、保存期限及预算。

文档中的时间容差、性能、准确率、费用和工期均为**建议目标或测算假设**，须经 PoC 和业务确认后冻结。官方服务说明已联网核对，引用集中见研究文档；价格没有作为供应商报价核实。
